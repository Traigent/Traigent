# Support

## Documentation

- Traigent documentation: <https://traigent.github.io/Traigent/>
- Getting started: [docs/getting-started/GETTING_STARTED.md](docs/getting-started/GETTING_STARTED.md)

## Questions and ideas

Ask in [GitHub Discussions](https://github.com/Traigent/Traigent/discussions).

## Bugs and feature requests

Open a [GitHub issue](https://github.com/Traigent/Traigent/issues/new/choose)
using the bug report or feature request form. Please include the Traigent
version, Python version, and a minimal reproduction.

## Security issues

Do not open a public issue for a suspected vulnerability. Follow
[SECURITY.md](SECURITY.md) and email security@traigent.ai.

## Commercial support and licensing

For commercial licensing or commercial support, contact legal@traigent.ai.
See [COMMERCIAL-LICENSE.md](COMMERCIAL-LICENSE.md) for the licensing options.

## Community and conduct

Questions about contributing or the code of conduct can go to
opensource@traigent.ai. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
